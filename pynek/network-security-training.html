Network Security Training

Design, harden and defend enterprise networks — then attack them, so you understand both sides of every control.

Trainings

Overview

This program builds networks from the ground up and then breaks them. You configure the routing, the firewall rules and the segmentation yourself, attack what you built, and lock it down again — which is the only way the theory actually sticks.

Every module is lab-backed, using the same classes of equipment and tooling found in production environments.

What you get

  • Networking fundamentals — TCP/IP, routing, switching
  • Firewalls, IDS/IPS and network segmentation
  • VPNs, secure remote access and Zero Trust concepts
  • Wireless security and rogue-device detection
  • Traffic capture and analysis with Wireshark
  • Pynek certificate of completion

Curriculum

What you’ll study

Build and configure

  • TCP/IP, subnetting, routing and switching
  • Firewall architecture and rule design
  • Network segmentation and VLANs
  • VPNs and secure remote access
  • Wireless network design and hardening

Attack and defend

  • Reconnaissance and network scanning
  • Traffic capture and analysis with Wireshark
  • Common network attacks and how they present
  • IDS/IPS tuning and detection engineering
  • Hardening baselines and configuration review

Suited to IT and network administrators moving into security, students building a practical portfolio, and teams responsible for keeping an enterprise network defensible.
